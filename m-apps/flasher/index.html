M-Flasher

Back up, restore and reinstall the firmware of an M-VAVE FM-1 or SMK-37 Pro / Elite, and install m-bootloader.

Free for Windows, macOS and Linux

What it does

It talks to the chip's built-in USB download mode, so it also works when the firmware on the unit is broken.

  • Back up the whole flash, and restore a backup.
  • Install firmware from .fwsc packages, as downloaded.
  • Install m-bootloader, or put the stock one back.
  • A flash map shows what each part of the flash holds and, before a write, exactly what will change.
  • Checks the package is for this model, writes only what changes, and verifies everything written.

Support

M-Flasher is free. Its apps aren't signed yet: that's why Windows and macOS ask for an extra confirmation the first time. Signing for macOS needs Apple's developer program, $99 every year: donations go to that first, and what's left after a year's signing goes to the next.
