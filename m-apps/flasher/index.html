M-Flasher

Back up, restore and reinstall the firmware of an M-VAVE FM-1 or SMK-37 Pro / Elite, and install m-bootloader.

On a computer Windows, macOS, Linux

Talks to the chip's built-in USB download mode, so it also works when the firmware on the unit is broken.

  • Back up and restore the whole flash
  • Install firmware from .fwsc packages
  • Install m-bootloader, or put the stock bootloader back
Download

In a browser experimental beta

Over USB MIDI, from a computer or a phone, with nothing to install. Works through the unit's running firmware, or m-bootloader's MIDI mode.

  • Back up, restore and install firmware
  • Install m-bootloader through the firmware's update
  • Chrome, Edge, Brave or Firefox; on iOS, an app with Web MIDI
