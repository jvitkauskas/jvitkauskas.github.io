How to use M-Flasher

A step-by-step guide for the M-VAVE FM-1 and SMK-37 Pro / Elite. No technical knowledge needed. If something doesn't work, see If something goes wrong.

  1. What you need
  2. Install M-Flasher
  3. Connect your unit
  4. Make a backup first
  5. Install a firmware
  6. Install m-bootloader
  7. Go back to a backup
  8. When you're done

1What you need

  • Your FM-1 or SMK-37 Pro / Elite. The Fame MiniFM is an FM-1 under another name, and works the same.
  • A computer with Windows 10 or 11, macOS 11 or newer, or Linux.
  • A USB cable that carries data. Some cables only charge: if the computer never sees the unit, try another cable. Plug it straight into the computer, not through a hub or a dock.
  • If you want to install a firmware: its file, ending in .fwsc. Use it as you downloaded it. If it came inside a .zip, take the .fwsc out of it first.

2Install M-Flasher

Get it from the download page: it picks the right file for your computer. Then follow the steps for your system.

Windows
  1. Right-click the downloaded .zip and choose Extract All.
  2. Open the folder and double-click M-Flasher.exe.
  3. If Windows says "Windows protected your PC", click More info, then Run anyway. It says this because the app isn't signed yet.
  4. Later, when M-Flasher finds your unit, Windows asks whether to let it make changes: click Yes. M-Flasher needs this only to talk to the unit.

If Windows Security deletes it, see If something goes wrong.

macOS
  1. Open the downloaded .dmg and drag M-Flasher into Applications.
  2. Open M-Flasher from Applications. The first time, macOS refuses because the app isn't signed with an Apple certificate: close the message, open System Settings → Privacy & Security, scroll down, and click Open Anyway.
  3. When M-Flasher finds your unit, it asks for your Mac's password, and macOS asks once whether M-Flasher may access a removable volume (that's the unit): click Allow.

Start M-Flasher soon after you connect the unit: if it waits too long, macOS can take the unit out of download mode after about half a minute. Just connect it again.

Linux
  • Ubuntu, Debian, Linux Mint, Raspberry Pi OS: in a terminal, in the folder with the file, run sudo apt install ./m-flasher_…_amd64.deb (the name of the file you downloaded).
  • Fedora, RHEL, openSUSE: sudo dnf install ./m-flasher-….rpm, or on openSUSE sudo zypper install ./m-flasher-….rpm.
  • Other distributions: extract the .tar.gz and follow its README.txt.

Then connect the unit (unplug and plug it in again if it was connected), and start M-Flasher from your app menu. Start it as yourself, not with sudo.

3Connect your unit

M-Flasher talks to your unit in its download mode, a special mode built into its chip that works even when the firmware is broken. How to get there depends on what your unit runs now. Pick the first one that fits:

  • It works normally: switch it on, connect it, and start M-Flasher. Under HOW TO CONNECT, M-Flasher shows your unit with a DOWNLOAD MODE button. Click it, and the unit restarts into download mode by itself.
  • It has m-bootloader: hold REC (on the SMK-37: SEQ REC) while you switch it on.
  • It runs Felucca, SLOOP or Snoop37: hold OCT− and OCT+ together for 5 seconds.
  • Its firmware doesn't start: it's often in download mode already. Just connect it.

M-Flasher finds the unit by itself, reads it for a second or two, and shows USB CONNECTED · DOWNLOAD MODE with the model, the firmware and the bootloader.

That's normal: in download mode the unit's own screen doesn't change, and nothing new appears in Explorer or Finder.

Original M-VAVE unit? With M-VAVE's own bootloader and firmware, no key combination gets you into download mode: use the DOWNLOAD MODE button.

4Make a backup first

  1. Click BACKUP FULL FLASH.
  2. Click SAVE FULL BACKUP. It takes a second or two.

The backup holds everything on the unit: firmware, settings, presets, sounds and its factory calibration. Backups go to Documents → M-Flasher → backups, and the BACKUPS link at the top of the window opens that folder.

Good to know: M-Flasher also saves a backup by itself before every change it makes, so you can always go back. Keep a copy of your first backup somewhere safe.

5Install a firmware

  1. Click FLASH FIRMWARE.
  2. Click CHOOSE FILE and pick the .fwsc file. The map on the right marks what will change.
  3. Click REVIEW & FLASH. A summary shows what will be written, with a warning if something needs your attention.
  4. Click WRITE … SECTORS. It takes about ten seconds. Don't unplug or switch off the unit until it says it's done.

Your settings, presets and Bluetooth pairings stay as they are, and so does the unit's bootloader. M-Flasher checks that the file is for your model before it writes anything.

Switching to a very different firmware? Settings saved by the old one can confuse the new one, and M-Flasher warns you. To go back to the old firmware cleanly, restore a backup made while it was installed.

FM-1 sold from late 2026? These have a newer memory chip, shown as (new) next to FLASH CHIP. Some custom firmwares made before it came out don't fully work on it, for example not keeping settings. Check with the firmware's author before installing it.

6Install m-bootloader (recommended)

The bootloader is the small program that starts your unit. m-bootloader replaces M-VAVE's with one that has a recovery menu, so you can always get back into download mode from the unit's keys, even if a firmware stops working.

  • Download mode: hold REC (SMK-37: SEQ REC) while switching on.
  • Recovery menu: hold PLAY (SMK-37: SEQ PLAY) while switching on.

How to install it

When M-Flasher sees M-VAVE's original bootloader, it asks "Install m-bootloader?". Click YES, look over the summary, and click WRITE … SECTORS.

Or any time: click FLASH BOOTLOADER, leave M-BOOTLOADER selected, click REVIEW & FLASH, then WRITE … SECTORS.

After an official M-VAVE update: M-VAVE's updater puts its own bootloader back. Install m-bootloader again afterwards.

Going back to M-VAVE's bootloader

Click FLASH BOOTLOADER, choose STOCK (FROM .FWSC), and pick an official M-VAVE firmware file for your model. Custom firmware files won't work for this.

7Go back to a backup

  1. Click RESTORE FULL FLASH.
  2. Pick a backup from the list, or click CHOOSE FILE to find one.
  3. Click REVIEW & RESTORE, then WRITE … SECTORS.

Only what's different is written, and the unit comes back exactly as it was when you made the backup.

Restoring an old backup? Tick Keep this unit's bootloader so a newer m-bootloader stays on the unit.

8When you're done

Unplug the unit, then switch it off and on again. It starts with its firmware as usual.

If something goes wrong

M-Flasher doesn't find my unit
  • Check the unit is in download mode (see Connect your unit). Its screen not changing is normal.
  • Try another USB cable: many cables only charge.
  • Plug it straight into the computer, not through a hub or dock, and try another USB port.
  • Connect only one unit at a time.
  • Switch the unit off and on, and put it in download mode again.
  • On Linux, if M-Flasher says to run sudo modprobe sg, do that in a terminal.
On a Mac, there's no DOWNLOAD MODE button although the unit is on

Your Mac may remember the unit under an old name from an earlier firmware. Unplug the unit, open Audio MIDI Setup (in Applications → Utilities), choose Window → Show MIDI Studio, select the greyed-out entry for your unit (it may be called "USB Composite Device"), and press Delete. Then plug the unit in again.

Windows Security says M-Flasher is a threat, or deleted it

That's a false alarm, which sometimes happens to a new release because it isn't signed yet. It's reported to Microsoft each time and usually clears within a few days. If you can't wait, and you downloaded it from the download page here (it comes from M-Flasher's releases on GitHub):

  1. Open Windows Security → Virus & threat protection → Protection history and pick the M-Flasher entry.
  2. If it says Threat quarantined: Actions → Restore. If Windows finds it again, choose Allow on device.
  3. If it says Threat blocked: Actions → Allow, then download it again.
The unit's screen shows BAD CONFIG

An older m-bootloader doesn't understand what a newer official FM-1 update left behind. Choose Boot app in its menu to start the firmware, then install the m-bootloader that comes with M-Flasher (see step 6).

M-VAVE's updater, or a firmware's "return to official" option, stops with FAILED -5

That can happen on a unit with m-bootloader: M-VAVE's updater on an SMK-37 running a custom firmware, or Melodee's Return to official V15, for example. Nothing was changed. Use M-Flasher instead: restore a backup, or install the firmware and then put M-VAVE's bootloader back (see step 6).

It's very slow

Some USB ports are much slower with the unit. Try another one: a port at the back of a desktop computer, next to the video outputs, is often faster. M-Flasher suggests this too when it notices.

Something else

Ask in the issues on GitHub, and copy what M-Flasher's OPERATION LOG says. Your backups stay in Documents → M-Flasher → backups whatever happens.
